APT

Debian and Ubuntu · amd64 · stable main

After verifying the repository key and installing it as /etc/apt/keyrings/freetime-repository.gpg, add this entry to your APT sources: 

deb [arch=amd64 signed-by=/etc/apt/keyrings/freetime-repository.gpg] https://repo.free-time.me/apt stable main

YUM / DNF

Fedora and RHEL · x86_64

Save this configuration as /etc/yum.repos.d/freetime-repository.repo and verify the key fingerprint before accepting it: 

[Freetime Repository]
name=Freetime Repository
baseurl=https://repo.free-time.me/yum/x86_64/
enabled=1
gpgcheck=1
repo_gpgcheck=1
gpgkey=https://repo.free-time.me/yum/x86_64/public.asc

Maven / Gradle

Libraries for Java and Kotlin. Add the following repository in your Gradle Kotlin DSL configuration: 

repositories {
    maven { url = uri("https://repo.free-time.me/maven") }
}
